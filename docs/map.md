# 맵 설계

2026-11-06 설계, 2026-11-07 게임에 넣음 (맨 아래 「게임 안 구현」).

> **2026-11-07: 사용자가 맵을 다시 짜기로 했어요.** 아래는 지금 게임에 들어간 실험실 맵이에요.

## 정한 것

- 적은 **여러 통로**로 들어오고, 플레이어는 **하나**를 지켜요.
- 지킬 것은 **산소탑**이에요 (이야기는 `defense-design.md` 3장).
- **산소탑 HP가 0이 되면 져요.** 전에 정했던 "문 HP"를 대신해요.
- 적은 산소탑과 플레이어를 공격해요.
- 방은 크게.
- 수도꼭지(물 웅덩이)·환풍기(기체를 한 방향으로 밂)·배수구(웅덩이를 빨아들임)는 맵에 처음부터 있지 않고, **게임 중간 상점이나 업그레이드로** 얻어요.

## 모양

통로들이 가운데에서 합쳐져 왼쪽 방으로 이어지고, 방 끝에 산소탑이 있어요. 방은 크게 (사용자 요청).

게임의 `LAB_TEMPLATE` (`src/run/rooms.ts`) 그대로예요.

```
####################################
####################################
###################===============EE
###################===============EE
#..................===============EE
#..................===============EE
#..................===##############
#..................===##############
#..................===============EE
#..aa..............===============EE
#..aa......p.......===============EE
#..................===============EE
#..................===##############
#..................===##############
#..................===============EE
#..................===============EE
###################===============EE
###################===============EE
####################################
####################################
####################################
```

`.` 방 바닥 · `=` 통로 철판 · `E` 적 입구 · `a` 산소탑 (2×2) · `p` 플레이어 시작 · `#` 벽

크기 (1칸 = 16px): 전체 36×21칸 (화면 480×270보다 커서 카메라가 따라감).
- 방: 18×12 (열 1~18, 행 4~15). 통로 묶음(행 2~17)보다 위아래로 2칸씩 좁아요.
- 합류 구역: 폭 3 (열 19~21, 행 2~17). 통로 셋이 여기서 만나 방으로 들어가요.
- 통로: 3개, 폭 4, 길이 14 (열 22~35). 끝 2칸(열 34~35)이 적 입구. 통로 사이 벽은 2칸.

## 그림 (Aseprite)

`art/lab/`에 있어요.
- `lab_tiles.aseprite` / `.png`: 16×16 타일 5개 (방 바닥 2종, 통로 바닥(줄무늬 철판), 벽 윗면, 벽면)
- `argon_tank.aseprite` / `.png`: 32×48, 바닥 2×2칸 차지. 보라색 띠와 "Ar" 창
- `map_mockup.png` (`_2x`는 2배): 첫 목업 (예전 배치: 방 18×13, 통로 폭 3). 지금 게임 맵 그림은 `lab_map_render_2x.png`

## 이 모양이 만드는 선택

- **통로에서 싸우기:** 벽이 가까워서 폭발로 밀린 적이 벽에 잘 부딪혀요 (+50%). 기체도 좁은 통로에 갇혀 오래 머물러요. 대신 통로마다 따로 막아야 해요.
- **방에서 싸우기:** 적이 모여서 폭발 한 번에 여럿이 맞아요. 대신 벽 충돌이 드물고 산소탑과 가까워서 위험해요.

## 제안 (아직 안 정함)

- 맵 전체가 한 화면에 들어오게 (지금 코드는 36×21칸이라 카메라가 따라다님).
- 웨이브 시작 전에 이번에 열리는 통로 입구에 경고 표시.
- 처음 웨이브는 통로 1~2개만 열고, 웨이브가 지날수록 늘림.
- 적은 통로에서는 길을 따라오고, 방에 들어오면 산소탑으로 곧장 감.
- 플레이어도 통로에 들어갈 수 있음. 던진 시약은 벽을 넘어가고, 기체와 웅덩이는 벽에 막힘.
- 스테이지마다 맵이 다르고, 맵 하나에서 웨이브 여러 개, 웨이브 사이에 보상.

## 나중에 정할 것

- 산소탑 HP.
- 통로 길이·폭, 방 크기.
- 적 종류 (사용자가 새 초안을 짜 주기로 함).

## 게임 안 구현 (2026-11-07)

`npm run dev` 뒤 `http://localhost:5173/?lab` 로 열면 허브 대신 실험실 맵이 나와요 (적은 아직 안 나옴).

- 배치: `src/run/rooms.ts`의 `LAB_TEMPLATE` (36×21 전체를 직접 적음). 사용자 스케치대로 왼쪽 방(18×12)이 통로 묶음(세로 16)보다 좁아서 합류 구역(폭 3)에서 위아래로 계단처럼 꺾여요. 통로 3개는 폭 4, 길이 14, 끝 2칸이 적 입구(`E`).
- 그림: `src/art/tileset.ts`의 `lab` 테마가 코드로 구워요. 방 바닥 = 8px 타일 2×2(긁힘·반사점. 배수구는 상점 장치라 안 그림), 통로 = 다이아몬드 철판 + 벽가 노란 경고선, 입구 = 노란 사선, 벽면 = 금속 패널 + 배관 + 청록 표시등, 벽 윗면 = 패널 격자 + 환기구. 탱크 자리(`a`)는 볼트 박힌 받침판.
- 산소탑은 `art/lab/oxygen_tower.png`를 불러와요 (`a` 2×2칸 위, 아래 줄이 막힘). 플레이어 시작은 `p`.
- 실험실은 천장 조명이 있는 밝은 방이라 주변광을 다른 방보다 밝게 뒀어요 (`RoomScene`의 `Lighting`).
- 구워진 결과: `art/lab/lab_map_render_2x.png` (2배). 바닥 배수구 무늬를 지우기 전에 뽑은 그림이라 배수구가 남아 있어요.
