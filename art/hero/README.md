# 주인공 스프라이트 교체 가이드

이 폴더에 **`hero_body.png`**, **`hero_elem.png`** 두 장을 넣으면 게임이 코드로 그린 주인공 대신 이 그림을 써요.
(`npm run dev`는 새로고침, 배포용은 `npm run build:play` → `play.html`에 그림이 같이 들어가요.)
파일이 없으면 기존 코드 생성 캐릭터가 나와요.

시작 파일: `template/` 폴더
- `template_guide.png` — 4배 확대 가이드 (칸·발밑선·중심선·캐릭터 영역·동작 이름·프레임 시간, 현재 그림이 흐리게 깔림)
- `template/hero_body.png`, `template/hero_elem.png` — 현재 캐릭터가 같은 배치로 들어 있는 1배 시트 (덧그리거나 지우고 새로 그리기)

템플릿은 `npm run dev` 후 `http://localhost:5173/dev/export.html`에서 언제든 다시 받을 수 있어요.

## 시트 규칙

- 한 칸 **32×32**, 시트 크기 **192×768** (가로 6칸 × 세로 24줄)
- 줄 순서 = 방향 3개 × 동작 8개
  - 방향: **아래(정면) → 위(뒷모습) → 옆(오른쪽을 봄, 왼쪽은 게임이 좌우 반전)**
  - 동작: 대기 · 달리기 · 구르기 · 내려베기 · 올려베기 · 시전 · 피격 · 사망
- 칸 번호 = 프레임 번호. 동작마다 쓰는 칸 수가 정해져 있어요 (가이드에서 어둡게 칠한 칸은 비워 두기)

| 동작 | 프레임 | 프레임별 시간(ms) | 메모 |
| --- | --- | --- | --- |
| 대기 | 4 | 320 · 160 · 320 · 160 | 반복 |
| 달리기 | 6 | 70 × 6 | 반복 |
| 구르기 | 5 | 40 · 60 · 60 · 60 · 80 | 0번 = 움츠리는 예비동작 |
| 내려베기 | 4 | 70 · 40 · 110 · 80 | 0 예비동작 → **1 스미어(궤적을 길게 늘인 모양)** → 2 타격 정지 → 3 회복 |
| 올려베기 | 4 | 70 · 40 · 110 · 80 | 내려베기와 같은 구조, 반대 방향 |
| 시전 | 4 | 90 · 50 · 140 · 80 | 검을 들어 올림 |
| 피격 | 2 | 80 · 120 | |
| 사망 | 3 | 150 · 200 · 600 | 정면 줄만 사용 (마지막 = 쓰러진 모습) |

공격 판정은 예비동작(첫 70ms)이 끝나는 순간 들어가요. 프레임 시간은 `src/art/heroSprites.ts`의 `DURS`에서 바꿀 수 있어요.

## 기준선

- **발밑 = y 26** (신발 맨 아랫줄). 게임은 이 줄을 캐릭터 위치로 써요 → 모든 프레임에서 맞춰야 떠 보이지 않아요
- **가로 중심 = x 16**
- 캐릭터 크기 약 **20×26px** (가이드의 초록 상자)

## 두 장으로 나누는 이유

| 파일 | 담는 것 | 색 |
| --- | --- | --- |
| `hero_body.png` | 원소와 상관없는 모든 것 (후드·망토 겉·옷·피부·신발·검 손잡이) + 외곽선 | 자유 (저채도 권장) |
| `hero_elem.png` | **원소 색이 들어갈 부분만** (망토 안감·장갑·눈·허리띠·**검날**) | **흰색~회색만** |

게임이 `hero_elem.png`에 원소 색을 곱해요(setTint). 원소를 바꾸면 이 부분이 **0.25초 동안 스르륵** 그 색으로 바뀌어요.
- 흰색 `#ffffff` = 원소색 그대로, 회색일수록 어두운 원소색 → **회색 단계로 음영**을 넣으면 돼요 (`#ffffff` · `#cdcdcd` · `#989898` · `#505050` 권장)
- 두 장은 같은 칸에 같은 위치로 겹쳐져요. 원소 부분은 body 쪽을 비워 두거나 아래 깔리는 색으로 두면 돼요

## 캐릭터 콘셉트 (의뢰용)

- **후드와 망토를 걸친 원소술사**, 한 손에 검
- 탑다운, 살짝 앞에서 내려다본 각도, **2.5등신** (후드가 큰 편)
- 얼굴은 **후드 그늘 속 눈 2픽셀만** (눈은 원소 레이어 → 원소색으로 빛남)
- 원소 레이어: 망토 안감 · 장갑 · 눈 · 허리띠 · 검날
- 본체는 **저채도** (남색 · 회색 · 갈색), 빛은 **왼쪽 위**에서
- 외곽선은 순검정보다 안쪽 색의 진한 버전(셀아웃) 권장
- 팔레트는 [Endesga 32](https://lospec.com/palette-list/endesga-32) 권장 (배경·적이 이 팔레트라 잘 어울림)

## 참고

- 직접 그린 그림을 쓰면 코드로 붙이던 포니테일·리본 스프링(2차 동작)은 꺼져요 → 망토 펄럭임 등은 프레임에 그려 주세요
- 프레임을 비워 두면 그 순간 캐릭터가 안 보이니, 쓰는 칸은 전부 채워 주세요
- 추천 도구: Aseprite(유료), Piskel(무료 웹), LibreSprite(무료)
