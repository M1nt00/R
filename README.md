# 원소 저글러 (가제)

원소 4개(불·물·바람·번개)를 실시간으로 바꿔 끼우며 반응을 꽂는 탑다운 픽셀아트 액션 로그라이트.
기획서: [`docs/design.md`](docs/design.md)

> 현재 단계: **다시 쌓는 중** — 시작 화면은 빈 공간에 주인공과 허수아비만 있어요.
> 원소 메커니즘(1~4 원소 전환, 원소 공격·스킬, 완벽 회피 흡수)은 빼고, 시약을 던지는 **화학 반응**으로 새로 만드는 중이에요.
> 적·보스·런·메타 성장 코드는 남아 있지만 포탈·제단을 치워서 지금은 들어갈 수 없어요 (아래 "한 판의 흐름"·"구현된 것"은 이전 버전 기준).

## 화학 반응 시험판 (새 반응 매커니즘)

규칙과 결정 사항은 설계 문서(「화학 반응 액션 로그라이트 설계 문서」)가 기준이에요. 바꿀 때는 문서를 먼저 고쳐요.

시약을 던지고 불(화염방사기)로 불씨를 붙여서 실제 화학 반응을 일으켜요. 떨어진 자리에 기체 구름이 생기고, **같은 구름 안에 던져야** 합쳐져요.
화면 위 가운데 화학식은 **무언가와 합쳐질 때만** 떴다가 잠시 뒤 서서히 사라져요. 땅 위 구름·물·나트륨·열매에는 작은 화학식 라벨이 둥둥 떠 있어요.

**수소 규칙 두 줄**
1. 수소에 불이 붙으면 터지고, 언제나 물이 남는다 (탄다 = 산소와 결합한다 = 물)
2. 산소가 섞여 있으면 **큰 폭발**, 없으면 공기 중 산소로 타서 **약한 폭발**

| 하는 법 | 화면 위 | 결과 |
| --- | --- | --- |
| 1 수소 ×2 (같은 자리) | H + H → H₂ | 저절로 결합, 수소 구름 |
| 2 산소 ×2 (같은 자리) | O + O → O₂ | 저절로 결합, 산소 구름 |
| 4 탄소 + 2 산소 | C + O → CO | 저절로 결합, 일산화탄소 구름 |
| 거기에 2 산소 하나 더 (또는 산소 구름에 탄소) | CO + O → CO₂ / C + O₂ → CO₂ | 이산화탄소 구름 |
| 수소 구름에 산소 | H₂ + O (반응식 없이) | 섞이기만 함 (불씨가 있어야 반응) |
| 수소만 있는 구름에 불 | 2H₂ + O₂ → 2H₂O | 공기 중 산소로 타서 약한 폭발 (옅은 파랑), 물 |
| 산소가 섞인 구름에 불 | H₂ + O → H₂O / 2H₂ + O₂ → 2H₂O | 큰 폭발 + 넉백, 물 |
| 물에 3 나트륨 | 2H₂O + 2Na → 2NaOH + H₂ | 0.7초 지글 → 폭발. 생긴 수소도 바로 타서 물 2를 쓰고 1이 돌아옴 |
| 이산화탄소 구름이 물웅덩이 위에 | 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ | 광합성: 포도당 열매, 그 구름의 CO₂가 O₂로 (CO₂ 하나 + 물 1 사용) |
| 열매 줍기 (HP가 닳았을 때) | C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O | 세포 호흡, HP +25 |

- 폭발은 근처 수소 구름에 옮겨붙어요 (연쇄). 플레이어는 자기 반응에 맞지 않아요
- 광합성은 빛·식물 없이 물 위의 이산화탄소만으로 일어나요 (게임이라 과장). 반응할 때 위에서 햇빛이 내리쬐는 연출만 나와요. 수소를 터뜨려 물을 만들고 그 위에 탄소 + 산소 둘을 던지면 돼요
- 광합성으로 나온 산소는 그 구름에 남아요. 거기에 수소를 섞어 불을 붙이면 큰 폭발로 이어져요
- 화염방사기는 **좌클릭 한 번에 불줄기를 한 번 뿜는 드래곤 브레스**예요 (쿨타임 1.5초, 시약 슬롯 오른쪽 "클릭" 칸에 표시). 불씨일 뿐 직접 피해는 없어요
  - 그림은 `art/fx/breath.aseprite` (오른쪽을 보는 88×28, 10프레임 0.71초) → `art/fx/breath.png` 가로 시트로 내보내서 씀. 노즐은 그림 왼쪽 끝, 위에서 16px. 조준 방향으로 돌리고, 왼쪽을 볼 땐 위아래를 뒤집어서 불이 늘 위로 피어올라요
  - 판정은 보이는 그대로: 그 프레임의 뜨거운 색(흰·노랑·호박·주황) 픽셀이 닿은 수소 구름에 불이 붙고, 불줄기는 벽에서 잘려요. 1~5프레임 동안은 손을 따라가고, 그 뒤로는 떨어져 나가 그 자리에서 식어요
  - 그림을 고치면 aseprite에서 `breath.png`로 다시 내보내기 (File › Export Sprite Sheet, 가로 한 줄, 여백 없음). 프레임 수나 길이를 바꾸면 `src/chem/flamethrower.ts`의 `DURS`도 같이
  - 소리는 녹음 파일 `art/sfx/breath.wav` (Soundza "Mouth Blow Hiss", 16비트 모노 0.92초). 쏠 때마다 음높이를 ±5% 흔들어요. 파일이 없거나 못 불러오면 예전 합성음이 대신 나요. 크기·흔들림은 `src/audio/sfx.ts`의 `SAMPLES`에서 조절
- 이펙트 그림 (`art/fx/`, aseprite 원본 → 같은 이름 가로 시트 png, 재생은 `src/chem/fx.ts`)
  - 폭발 `boom_*` 8프레임 0.61초: 흰 섬광 → 빛줄기 → 불덩이 → 연기로 흩어짐. 큰 폭발은 반지름 44 이하면 `boom_s`(90×109), 넘으면 `boom_l`(144×175). 약한 폭발은 `boom_w`(옅은 파랑 + 흰 김), 나트륨은 `boom_na`(노란 불 + 흰 연무). 실제 피해 범위는 바닥 고리(코드)가 보여줘요
  - 시약병 `shatter.aseprite` 6프레임 0.4초: `glass` 레이어(유리 조각) → `shatter_glass.png`, `splash` 레이어(내용물·김, 흰~회색) → `shatter_splash.png`. 내용물은 게임이 시약 색을 곱해요. 나트륨은 덩어리로 남아서 유리만
  - 그림을 고치면 레이어·프레임별로 가로 한 줄 시트로 다시 내보내기. 크기·프레임 수·시간을 바꾸면 `fx.ts`의 `FX` 표(크기, 기준점 ox·oy, `durs`)도 같이
  - 히트스톱 동안은 멈춰서 폭발 첫 섬광이 잠깐 정지해 보여요
  - 코드로 그리는 것: 날아가는 병 꼬리, 광합성 빛기둥(열매가 열릴 때 가운데가 번쩍, 웅덩이에서 방울이 올라옴, 열매에 십자 반짝임)
- 물은 둥근 웅덩이로 생기고, 눈에 보이게 닿은 물끼리 하나로 합쳐져 양이 늘어요 (라벨 3H₂O 등)
- 나트륨은 물이 아닌 곳에 떨어지면 바닥에 남아 있다가, 그 자리에 물이 생기면 그때 반응해요
- 색은 분자 모형 관례색(CPK): 수소 흰색, 산소 빨강, 나트륨 보라, 탄소 짙은 회색. 일산화·이산화탄소는 색 없는 기체라 회색
- 코드: `src/chem/chemistry.ts`(던지기·구름·반응·폭발·광합성·열매), `src/chem/fx.ts`(그림 이펙트 재생), `src/chem/flamethrower.ts`(화염방사기), `src/chem/formula.ts`(아래 첨자 화학식 그리기), 위 가운데 반응식 연출은 `src/scenes/UIScene.ts`

## 실행

### 그냥 해보기 (설치 필요 없음)

**`play.html`을 더블클릭**해서 브라우저(크롬·엣지 권장)로 열면 바로 시작돼요.
코드가 전부 한 파일에 들어 있어서 인터넷이나 설치 없이 동작해요.

> `index.html`은 개발 서버용이라 더블클릭으로는 안 켜져요 (브라우저 보안 정책).

### 개발 모드

[Node.js](https://nodejs.org) 설치 후:

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 열기. 코드를 고치면 바로 반영돼요.

### 빌드

- `npm run build:play` → `play.html` 다시 만들기 (코드 고친 뒤 실행)
- `npm run build` → 웹 배포용 `dist/`

## 한 판의 흐름

1. **원소의 성소(허브)** — 허수아비로 연습(DPS 표시), 제단에서 원소 정수로 성장, 포탈로 출발
2. **잿빛 회랑 7개 방 + 보스** — 방을 클리어하면 문 위에 다음 보상이 표시되고 경로를 고름
   - 전투(반응 강화 3지선다 / 골드), 엘리트(유물 3지선다), 상점, 회복의 샘
3. **잿불 골렘** — 원소 실드가 페이즈마다 바뀜 (증발 → 빙결 → 과부하로만 파괴)
4. 죽거나 이기면 성소로. 원소 정수와 반응 숙련도는 남음

## 구현된 것

**아트·연출**
- 480×270 원본 해상도로 그리고 캔버스 전체만 정수배 확대 (스프라이트 개별 확대 없음 → 믹셀 없음)
- 팔레트: [Endesga 32](https://lospec.com/palette-list/endesga-32). 단계마다 색조 이동(그림자 → 파랑·보라, 하이라이트 → 노랑), 외곽선은 셀아웃
- 원소 레이어는 원소별 4단 색 램프로 구워서 교체 (검날·머리띠가 원소마다 다른 음영)
- 프레임별 시간이 다른 애니메이션, 휘두르는 순간의 스미어 프레임, 공격·구르기 예비동작
- 후드 끝자락·허리띠 끈은 스프링 시뮬레이션(2차 동작), 구르기 땐 살짝 떠오르며 그림자가 줄어듦
- 원소 이펙트는 ADD 블렌드로 발광, 검날·투사체에만 은은한 postFX 글로우, 디더링 비네트
- 카메라는 부드럽게 따라가며 마우스 쪽으로 살짝 앞서감
- 주인공은 망토로 몸을 싸맨 후드 캐릭터(48×48, `art/hero/`, 대기·달리기만 완성, 나머지 동작은 임시로 서 있는 포즈. 파일을 지우면 아래 코드 생성 그림으로 돌아감)
- 픽셀아트를 코드로 생성: 후드 원소술사 3방향 × 대기·달리기·구르기·내려베기·올려베기·검 들기·피격·사망. 망토 안감·장갑·눈·허리띠·검날이 원소색 (`art/hero/`에 그림 파일이 없을 때만 씀), 적 5종, 위습, 보스(64×64), 타일셋, 소품, UI 아이콘
- 본체 + 원소 레이어(흰색 → `setTint`) 구조라 같은 그림으로 원소별 적 20종
- 조명: 어두운 주변광 위로 화로·원소 공격·반응 폭발·불타는 풀·장판이 방을 밝힘
- 사망 시 현재 프레임 픽셀이 그대로 흩어지는 분해 연출, 폭발 그을음 자국, 광채, 잔상, 먼지
- 한글 픽셀 폰트(Galmuri 7·9·11 — 설계 크기 8·10·12px 그대로), 절차적 효과음(불 뿜기만 녹음 파일) + 지역별 배경음

**전투**
- 1차 6 · 중첩 4 · 지형 5 · 2차 10 반응, 완벽 회피 흡수, 적도 원소를 가짐
- 적 5유형(돌격·사수·자폭·방패·소환사) × 원소 4, 엘리트 수식어 5종(신속·거대화·이중 원소·분열·원소 실드)
- 방패형은 정면 피해 무효(뒤로 돌거나 낙뢰·장판), 소환사형은 위습 소환

**진행**
- 방 템플릿 8종 + 상점·샘·보스방, 문 보상 선택, 반응 강화 15종(3단계 → 극의), 유물 8종, 골드·상점
- 메타 성장: 스탯 6종, 2차 반응 10종 해금(숙련 30회 + 정수), `localStorage` 저장
