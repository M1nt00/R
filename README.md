# 원소 저글러 (가제)

원소 4개(불·물·바람·번개)를 실시간으로 바꿔 끼우며 반응을 꽂는 탑다운 픽셀아트 액션 로그라이트.
기획서: [`docs/design.md`](docs/design.md)

> 현재 단계: **다시 쌓는 중** — 시작 화면은 빈 공간에 주인공과 허수아비만 있어요.
> 전투·반응·런·보스·메타 성장 코드는 그대로 남아 있지만, 포탈·제단을 치워서 지금은 들어갈 수 없어요 (아래 "한 판의 흐름"은 이전 버전 기준).

## 실행

### 그냥 해보기 (설치 필요 없음)

**`play.html`을 더블클릭**해서 브라우저(크롬·엣지 권장)로 열면 바로 시작돼요.
코드가 전부 한 파일에 들어 있어서 인터넷이나 설치 없이 동작해요.

> `index.html`은 개발 서버용이라 더블클릭으로는 안 켜져요 (브라우저 보안 정책).

### 개발 모드

[Node.js](https://nodejs.org) 설치 후:

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 열기. 코드를 고치면 바로 반영돼요.

### 빌드

- `npm run build:play` → `play.html` 다시 만들기 (코드 고친 뒤 실행)
- `npm run build` → 웹 배포용 `dist/`

## 한 판의 흐름

1. **원소의 성소(허브)** — 허수아비로 연습(DPS 표시), 제단에서 원소 정수로 성장, 포탈로 출발
2. **잿빛 회랑 7개 방 + 보스** — 방을 클리어하면 문 위에 다음 보상이 표시되고 경로를 고름
   - 전투(반응 강화 3지선다 / 골드), 엘리트(유물 3지선다), 상점, 회복의 샘
3. **잿불 골렘** — 원소 실드가 페이즈마다 바뀜 (증발 → 빙결 → 과부하로만 파괴)
4. 죽거나 이기면 성소로. 원소 정수와 반응 숙련도는 남음

## 구현된 것

**아트·연출**
- 480×270 원본 해상도로 그리고 캔버스 전체만 정수배 확대 (스프라이트 개별 확대 없음 → 믹셀 없음)
- 팔레트: [Endesga 32](https://lospec.com/palette-list/endesga-32). 단계마다 색조 이동(그림자 → 파랑·보라, 하이라이트 → 노랑), 외곽선은 셀아웃
- 원소 레이어는 원소별 4단 색 램프로 구워서 교체 (검날·머리띠가 원소마다 다른 음영)
- 프레임별 시간이 다른 애니메이션, 휘두르는 순간의 스미어 프레임, 공격·구르기 예비동작
- 후드 끝자락·허리띠 끈은 스프링 시뮬레이션(2차 동작), 구르기 땐 살짝 떠오르며 그림자가 줄어듦
- 원소 이펙트는 ADD 블렌드로 발광, 검날·투사체에만 은은한 postFX 글로우, 디더링 비네트
- 카메라는 부드럽게 따라가며 마우스 쪽으로 살짝 앞서감
- 주인공은 PixelLab으로 생성한 후드 원소술사 스프라이트(48×48, `art/hero/`, 파일을 지우면 아래 코드 생성 그림으로 돌아감)
- 픽셀아트를 코드로 생성: 후드 원소술사 3방향 × 대기·달리기·구르기·내려베기·올려베기·검 들기·피격·사망. 망토 안감·장갑·눈·허리띠·검날이 원소색 (이전 은발 검사는 `HERO_STYLE`로 전환 가능), 적 5종, 위습, 보스(64×64), 타일셋, 소품, UI 아이콘
- 본체 + 원소 레이어(흰색 → `setTint`) 구조라 같은 그림으로 원소별 적 20종
- 조명: 어두운 주변광 위로 화로·원소 공격·반응 폭발·불타는 풀·장판이 방을 밝힘
- 사망 시 현재 프레임 픽셀이 그대로 흩어지는 분해 연출, 폭발 그을음 자국, 광채, 잔상, 먼지
- 한글 픽셀 폰트(Galmuri 7·9·11 — 설계 크기 8·10·12px 그대로), 절차적 효과음 + 지역별 배경음

**전투**
- 1차 6 · 중첩 4 · 지형 5 · 2차 10 반응, 완벽 회피 흡수, 적도 원소를 가짐
- 적 5유형(돌격·사수·자폭·방패·소환사) × 원소 4, 엘리트 수식어 5종(신속·거대화·이중 원소·분열·원소 실드)
- 방패형은 정면 피해 무효(뒤로 돌거나 낙뢰·장판), 소환사형은 위습 소환

**진행**
- 방 템플릿 8종 + 상점·샘·보스방, 문 보상 선택, 반응 강화 15종(3단계 → 극의), 유물 8종, 골드·상점
- 메타 성장: 스탯 6종, 2차 반응 10종 해금(숙련 30회 + 정수), `localStorage` 저장

## 구조

```
src/
  data/       reactions.json, enemies.json, boons.json, relics.json, meta.json  ← 밸런스는 여기서
  element/    elementState.ts, reactionEngine.ts, terrain.ts, data.ts, types.ts
  combat/     attacks.ts, damage.ts, hitstop.ts, fields.ts, projectiles.ts, vfx.ts, lighting.ts
  entities/   actor.ts, player.ts, enemy.ts, boss.ts, props.ts
  run/        runState.ts(런·문 보상), mods.ts(강화·유물 수정치), meta.ts(메타 성장), rooms.ts(방 템플릿)
  art/        palette.ts, pixel.ts(래스터라이저), heroSprites.ts, enemySprites.ts, propSprites.ts, tileset.ts
  audio/      sfx.ts (효과음 + 배경음 합성)
  scenes/     Boot, Room(허브·전투·상점·샘·보스), UI
dev/preview.html  생성된 스프라이트 시트 확대 미리보기 (npm run dev 후 /dev/preview.html)
dev/pick.html     주인공 프레임 골라 크게 보기 (?a=idle_down:0,attack_side:1&tint=f77622)
dev/export.html   주인공 그림판 템플릿 내보내기
```

- 화면: 480×270을 그대로 렌더링하고 창 크기에 맞는 최대 정수배로 확대. 방은 576×336이라 카메라가 따라다님
- 스프라이트를 손그림으로 바꿀 땐 같은 텍스처 키(`hero_body`, `hero_elem`, `charger_body` …)와 같은 프레임 순서로 덮어쓰면 됨

## 주인공 그림 교체

`art/hero/`에 직접 그린 `hero_body.png`·`hero_elem.png`를 넣으면 코드로 그린 주인공 대신 쓰여요. 규칙·템플릿·콘셉트는 [`art/hero/README.md`](art/hero/README.md).

## 개발용 옵션

주소 뒤에 `?dev`를 붙이면: `K` 정수 +50, `G` 골드 +200, `N` 방 즉시 클리어, `J` 다음 방, `B` 보스방으로, 제단에 메타 초기화 버튼.
