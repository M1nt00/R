# 원소 저글러 (가제)

원소 4개(불·물·바람·번개)를 실시간으로 바꿔 끼우며 반응을 꽂는 탑다운 픽셀아트 액션 로그라이트.
기획서: [`docs/design.md`](docs/design.md)

> 현재 단계: **로드맵 1단계(손맛) + 2단계(반응 엔진) 프로토타입** — 도형 아트, 웨이브식 테스트 방

## 실행

### 그냥 해보기 (설치 필요 없음)

**`play.html`을 더블클릭**해서 브라우저(크롬·엣지 권장)로 열면 바로 시작돼요.
코드가 전부 한 파일에 들어 있어서 인터넷이나 설치 없이 동작해요.

> `index.html`은 개발 서버용이라 더블클릭으로는 안 켜져요 (브라우저 보안 정책).

### 개발 모드

[Node.js](https://nodejs.org) 설치 후:

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 열기. 코드를 고치면 바로 반영돼요.

### 빌드

- `npm run build:play` → `play.html` 다시 만들기 (코드 고친 뒤 실행)
- `npm run build` → 웹 배포용 `dist/`

## 조작

| 입력 | 행동 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 기본 공격 (현재 원소) |
| 우클릭 | 원소 스킬 (원소별 쿨다운) |
| 1 / 2 / 3 / 4 | 불 / 물 / 바람 / 번개 전환 |
| 스페이스 | 구르기 (무적 0.3초, 2회 충전) |
| H | 도움말 (일시정지) |
| T | 2차 반응 10종 해금 토글 (메타 성장 전 테스트용) |
| M | 소리 켜기/끄기 |
| R | 사망 후 다시 시작 |

## 구현된 것

**1단계 — 손맛**
- 이동, 구르기(무적·충전), 원소 전환(공용 쿨다운 0.5초, 전환 직후 첫 공격 강화)
- 원소별 고정 공격 세트: 불 3연타/화염 돌진, 물 물줄기/물웅덩이, 바람 부채꼴 베기/회오리, 번개 낙뢰/순간이동 방전
- 타격감: 히트스탑(0.05초, 반응 0.1초), 넉백, 화면 흔들림, 흰색 피격 플래시, 구르기 잔상, 피해 숫자
- 절차적 애니메이션: 숨쉬기, 걷기 바운스, 스쿼시·스트레치, 공격 전진, 사망 분해, 전환 링

**2단계 — 반응 엔진**
- 원소 상태 컴포넌트(부착·남은 시간·중첩·잔여 상태)를 플레이어·적이 공유 → 적도 나에게 반응을 건다
- 1차 반응 6종, 중첩 반응 4종, 지형 반응 5종, 2차 반응 10종(T로 해금)
- 완벽 회피(구르기 시작 0.15초 안에 피격) → 공격 원소를 빼앗아 다음 공격에 실음
- 지형: 물웅덩이(서 있으면 물 부착), 마른 풀(들불 번짐 → 재 → 재생), 바람 통로(밀어냄)
- 적 3유형(돌격형·사수형·자폭형) × 원소 4 = 12종, 바닥 경고 표시
- 한 프레임 반응 수 상한(무한 연쇄 방지), 투사체·피해 숫자 오브젝트 풀링
- 반응마다 이름 텍스트 + 원소색 이펙트 + 합성 효과음, 2차는 흔들림·히트스탑 강화

## 구조

```
src/
  data/       reactions.json, enemies.json   ← 밸런스·반응은 여기서만 고치면 됨
  element/    elementState.ts, reactionEngine.ts, terrain.ts, data.ts, types.ts
  combat/     attacks.ts, damage.ts, hitstop.ts, fields.ts, projectiles.ts, vfx.ts
  entities/   actor.ts, player.ts, enemy.ts
  run/        waves.ts, roomLayout.ts   ← 3단계에서 방 연결·보상으로 교체 예정
  art/        palette.ts (24색), generatedSprites.ts (코드 생성 텍스처)
  audio/      sfx.ts (WebAudio 합성)
  scenes/     Boot, Room, UI
```

- 화면: 월드는 480×270, 캔버스는 2배(960×540)로 그려서 한글 HUD를 선명하게 유지
- 스프라이트: 32×32 프레임, 본체 레이어 + 흰색 원소 레이어(`setTint`) 2장 구조.
  손그림으로 바꿀 땐 같은 텍스처 키(`player_body`, `player_elem`, `enemy_<유형>_body` …)로 덮어쓰면 됨
